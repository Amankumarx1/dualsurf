# Comprehensive Command Reference: Active Directory & Identity Assessment Module

This document provides a complete, verified command catalog for the 4 Active Directory and identity assessment tools integrated into DualSurf: **BloodHound, SharpHound, Impacket, and NetExec**.

---

## 1. BloodHound

- **Purpose:** Active Directory graph-based relationship analysis tool that visualizes hidden privilege paths, Tier 0 asset exposures, and access-control relationships.
- **Binary / Container:** `bloodhound` / `bloodhound.exe` / Docker `specterops/bloodhound` (BloodHound CE)
- **Detected Host Status:** NOT INSTALLED / NOT LISTENING on ports `8080` (BloodHound CE) or `7474` (Neo4j)
- **Documentation URL:** [https://bloodhound.readthedocs.io/](https://bloodhound.readthedocs.io/)
- **Required Permissions:** Unprivileged user. Connects to local Neo4j database or BloodHound CE Docker container.

### Complete Option Set & Syntax Reference
```bash
# BloodHound Legacy Desktop Application (Electron)
bloodhound                       # Launch graphical application
bloodhound --no-sandbox          # Linux container / unprivileged namespace launch

# BloodHound Community Edition (Docker / Podman Deployment)
docker run -d -p 8080:8080 --name bloodhound specterops/bloodhound
docker compose -f bloodhound-ce.yml up -d

# DualSurf BloodHound Ingestion API
# Ingests JSON export files generated by SharpHound via DualSurf IPC:
# window.dualsurf.parseBloodHoundImport(jsonContent, fileName)

# CLI Helper Commands in DualSurf
ds ad graph status               # Test Neo4j (7474) and BloodHound CE (8080) ports
ds ad graph open                 # Launch BloodHound web interface in browser
ds ad report import users.json   # Parse and extract statistics from JSON file
```

### Categorized Command Workflows
| Category | Command | Applicability / Scope Status |
| :--- | :--- | :--- |
| **Diagnostic & Help** | `ds ad graph status` | Safe service diagnostic. (Status: `Executed & verified — correctly reports offline`). |
| **Applicable to Website** | **NOT APPLICABLE** | The target website (`www.amankumarx1.xyz`) is a static web application on Vercel CDN; no Active Directory graph exists for this target. |
| **Local Lab Only** | `ds ad report import lab_users.json` | Ingestion of authentic SharpHound collection archives from an authorized AD lab. |

## 2. SharpHound

- **Purpose:** Official C# and PowerShell data collector for BloodHound, collecting Active Directory objects, security descriptors, and session data.
- **Binary Name:** `SharpHound.exe` / `SharpHound.ps1` (Windows) / `bloodhound-python` (POSIX/Linux)
- **Detected Host Status:** NOT INSTALLED on host PATH
- **Documentation URL:** [https://bloodhound.readthedocs.io/en/latest/data-collection/sharphound.html](https://bloodhound.readthedocs.io/en/latest/data-collection/sharphound.html)
- **Required Permissions:** Standard domain user account. Session and local admin collection require network RPC/SMB access to domain endpoints.

### Complete Option Set & Syntax Reference
```bash
# Windows Native Syntax (SharpHound.exe)
SharpHound.exe -c <Method> -d <Domain> [Options]

# Collection Methods (-c / --CollectionMethods)
# Default: Group, LocalAdmin, Session, Trusts
SharpHound.exe -c Default -d corp.local

# DCOnly: Stealthy DC-only LDAP queries (no endpoint traffic)
SharpHound.exe -c DCOnly -d corp.local

# All: Comprehensive collection across all methods
SharpHound.exe -c All -d corp.local

# ComputerOnly: Collects computer and service account attributes
SharpHound.exe -c ComputerOnly -d corp.local

# Session: Collects active logged-on user sessions via NetSessionEnum
SharpHound.exe -c Session -d corp.local

# LoggedOn: Collects logged on users via privileged Remote Registry
SharpHound.exe -c LoggedOn -d corp.local

# Common Configuration Options
--domaincontroller 10.0.0.1      # Target specific Domain Controller
--outputdirectory "./ad_evidence" # Destination folder for JSON archives
--zipfilename "audit_corp"       # Custom ZIP archive name
--throttle 1000                  # Milliseconds delay between requests
--jitter 20                      # Add percentage jitter to requests
--stealth                        # Exclude noisy port scans

# Linux / Cross-Platform Syntax (bloodhound-python)
bloodhound-python -u 'user' -p 'pass' -d 'corp.local' -dc '10.0.0.1' -c Default -ns '10.0.0.1'
```

### Categorized Command Workflows
| Category | Command | Applicability / Scope Status |
| :--- | :--- | :--- |
| **Diagnostic & Help** | `SharpHound.exe --help`<br>`bloodhound-python -h` | Safe diagnostic check. |
| **Applicable to Website** | **NOT APPLICABLE** | The target website has no LDAP/Active Directory domain controller. |
| **Local Lab Only** | `SharpHound.exe -c Default -d lab.local --outputdirectory "./evidence"` | Authorized collection within an explicit AD lab boundary. |

## 3. Impacket Utilities Suite

- **Purpose:** A collection of Python classes and standalone security assessment scripts for working with network protocols (SMB, MSRPC, LDAP, Kerberos).
- **Binary / Package:** Python library `impacket` + standalone script suite
- **Detected Host Status:** NOT INSTALLED in Python 3.13.14 environment
- **Documentation URL:** [https://github.com/fortra/impacket](https://github.com/fortra/impacket)
- **Required Permissions:** Unprivileged user. Network reachability to target ports (389, 445, 135, 88).

### Complete Option Set & Syntax Reference
```bash
# 1. GetADUsers.py (Read-Only LDAP Directory Enumeration)
GetADUsers.py -all <domain>/<user>:<password> -dc-ip <dc_ip>
GetADUsers.py -all corp.local/ -dc-ip 10.0.0.1 # Anonymous / null session

# 2. GetUserSPNs.py (Kerberoasting Audit)
GetUserSPNs.py <domain>/<user>:<password> -dc-ip <dc_ip> -request
# Audits which user accounts have SPNs configured with RC4 / AES encryption

# 3. lookupsid.py (Domain SID / RID Cycling)
lookupsid.py <domain>/<user>:<password>@<target_ip>
lookupsid.py corp.local/guest@10.0.0.1 # Guest enumeration of SIDs

# 4. rpcdump.py (MSRPC Endpoint Mapping)
rpcdump.py 10.0.0.1              # Dumps listening RPC interfaces and dynamic ports

# 5. samrdump.py (SAM & LSA Policy Enumeration)
samrdump.py <domain>/<user>:<password>@<target_ip>

# 6. smbclient.py (SMB Protocol & Share Verification)
smbclient.py <domain>/<user>:<password>@<target_ip>
# Interactive commands: shares, use <share>, ls, cat, put, get
```

### Categorized Command Workflows
| Category | Command | Applicability / Scope Status |
| :--- | :--- | :--- |
| **Diagnostic & Help** | `python -m pip show impacket`<br>`ds ad impacket` | Safe diagnostic check. (Status: `Executed & verified via DualSurf CLI`). |
| **Applicable to Website** | **NOT APPLICABLE** | Target `https://www.amankumarx1.xyz/` does not expose SMB, LDAP, or MSRPC. |
| **Local Lab Only** | `rpcdump.py 192.168.1.10`<br>`GetUserSPNs.py lab.local/audit:pass -dc-ip 192.168.1.10` | Read-only protocol diagnostics in an authorized AD environment. |

## 4. NetExec (`nxc`)

- **Purpose:** Multi-protocol network service and identity assessment utility (successor to CrackMapExec).
- **Binary Name:** `nxc` / `nxc.exe` / `netexec`
- **Detected Host Status:** NOT INSTALLED on host PATH
- **Documentation URL:** [https://www.netexec.wiki/](https://www.netexec.wiki/)
- **Required Permissions:** Unprivileged user. Outbound TCP network connectivity to ports 445 (SMB), 389/636 (LDAP), 5985/5986 (WinRM).

### Complete Option Set & Syntax Reference
```bash
# General Syntax
nxc <protocol> <target> [options]

# Protocol Discovery (SMB)
nxc smb 10.0.0.1                 # Fingerprint host OS, build, domain, and SMB signing
nxc smb 10.0.0.0/24 --gen-relay-list smb_relay.txt # Generate list of hosts without SMB signing
nxc smb 10.0.0.1 -u 'guest' -p '' --shares # Check accessible shares

# Protocol Discovery (LDAP)
nxc ldap 10.0.0.1                # Check LDAP signing, channel binding, domain name
nxc ldap 10.0.0.1 -u 'user' -p 'pass' -M laps # Audit LAPS configuration
nxc ldap 10.0.0.1 -u 'user' -p 'pass' --trusted-for-delegation # Delegation audit

# Logging & Export
nxc smb 10.0.0.1 --export-json results.json
nxc --help                       # Display all supported protocol modules
```

### Categorized Command Workflows
| Category | Command | Applicability / Scope Status |
| :--- | :--- | :--- |
| **Diagnostic & Help** | `nxc --version`<br>`nxc --help` | Safe diagnostic check. |
| **Applicable to Website** | **NOT APPLICABLE** | Target does not run SMB or LDAP services. |
| **Local Lab Only** | `nxc smb 192.168.1.0/24 --gen-relay-list unsigned.txt` | Read-only network signing audit in authorized lab. |
